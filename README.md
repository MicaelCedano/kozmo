# KOZMO Pad y KOZMO Pad Ultra — landing fotográfica

Proyecto independiente de la versión anterior. Ejecuta `npm install` y `npm run dev`. Preparado para Next.js en Vercel.

Las fotografías reales se colocan en `public/images/kozmo/`; allí están los nombres y dimensiones recomendadas. Activa cada imagen en `components/product-image.tsx` después de incorporarla. Los marcos actuales son espacios reservados, no imágenes del producto.

Las especificaciones y el enlace de WhatsApp se completarán una vez verificados. La animación respeta la preferencia de movimiento reducido.
